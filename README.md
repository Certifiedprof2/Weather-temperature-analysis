# Weather Temperature Analysis with NumPy

## Project Overview

This project is a beginner-to-intermediate NumPy project focused on analyzing temperature data from three locations in Nigeria: **Lagos, Abuja, and Ibadan**.

The project was completed as part of my NumPy hands-on practice. It helped me understand how NumPy arrays can be used to store numerical data, perform calculations, and compare values efficiently.

## Objectives

The main objectives of this project were to:

- Import and work with NumPy.
- Convert Python lists into NumPy arrays.
- Understand 1D and 2D arrays.
- Identify array dimensions, shape, data type, and size.
- Perform element-wise calculations.
- Compare temperature data between locations.
- Analyze numerical data without relying on `for` loops.
- Develop basic data analysis skills using NumPy.

## Dataset

The project uses temperature data recorded over five days for three locations:

- Lagos
- Abuja
- Ibadan

### Temperature Data

| Day | Lagos (°C) | Abuja (°C) | Ibadan (°C) |
|---|---:|---:|---:|
| Monday | 27.5 | 25.0 | 26.5 |
| Tuesday | 29.0 | 28.0 | 28.5 |
| Wednesday | 30.5 | 29.5 | 29.0 |
| Thursday | 28.0 | 30.0 | 27.5 |
| Friday | 31.0 | 32.0 | 30.5 |

## Tools Used

- Python
- NumPy
- Jupyter Notebook
- GitHub

I used NumPy properties such as: .ndim .shape .dtype .size

# Findings

Some observations from the analysis include:

Lagos recorded higher temperatures than Abuja on Monday, Tuesday, and Wednesday.
Abuja recorded higher temperatures than Lagos on Thursday and Friday.
Abuja recorded the highest single temperature in the dataset at 32.0°C.
NumPy made it possible to perform calculations on multiple temperature values at once without using a for loop.

#Conclusion

This project helped me understand how NumPy arrays can be used to work with numerical data. I practiced creating arrays, inspecting their properties, performing calculations, and comparing data between different locations.

This project is part of my ongoing journey in Python and Data Analytics.
